# Frontend App

React frontend for Stage 2.

## Features

- All notifications page
- Priority notifications page
- Type filter for Event, Result, and Placement
- Limit selector for top priority notifications
- Page query support for the notifications API
- New/viewed state stored in the browser
- Material UI components and native CSS only
- Protected API and log API calls using the bearer token from `.env`

## Run

Create `.env` from `.env.example` and add the bearer token.

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:3000
```
